# @medano-ui/fonts

medano Sans — tipografía variable (woff2, pesos 100–900) del design system [medano](https://github.com/BraianVaylet/bv-medano-ui). v1 deriva de [Hanken Grotesk](https://fonts.google.com/specimen/Hanken+Grotesk) (SIL OFL 1.1) con alias de familia; subsets `latin` y `latin-ext`.

## Instalación

```bash
pnpm add @medano-ui/fonts
```

## Uso

```css
@import '@medano-ui/fonts/medano-sans.css';

body {
  font-family: 'medano Sans', system-ui, sans-serif;
}
```
