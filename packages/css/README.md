# @medano-ui/css

Reset y estilos base de [medano](https://github.com/BraianVaylet/bv-medano-ui), framework-agnostic (Astro, HTML puro). Requiere las variables de `@medano-ui/tokens`.

## Instalación

```bash
pnpm add @medano-ui/css @medano-ui/tokens
```

## Uso

```css
@import '@medano-ui/tokens/vars.css';
@import '@medano-ui/css/base.css';
```
